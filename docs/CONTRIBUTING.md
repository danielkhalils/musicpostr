# Documentação do Projeto

## Estrutura do Projeto
* `src/`: Onde reside todo o código-fonte.
* `src/app/`: Onde você criará seus componentes, serviços e lógica de negócio.
* `src/app/app.component.ts`: O componente raiz (root) da sua aplicação.
* `angular.json`: Arquivo de configuração do projeto.
* `package.json`: Gerenciador de dependências e scripts.

## Guia da CLI
Para acelerar o desenvolvimento, use os comandos integrados:

| Ação | Comando |
| :--- | :--- |
| Criar Componente | `ng g c nome` ou `ng generate component nome-do-componente`|
| Criar Serviço | `ng g s nome` ou `ng generate service nome-do-servico`|
| Criar Módulo | `ng g m nome --routing` ou `ng generate module nome-do-modulo --routing`|

## Primeiros Passos
1. Execute `npm install` para instalar as dependências.
2. Utilize `ng serve` para iniciar o servidor de desenvolvimento.
